# Juggle Jumps 🐴⚽

A juggling practice game for the road to **100 juggles in a row**.
Every juggle jumps the horse over a fence; a drop makes it trip.

- **4 worlds:** Home Barn (3 drops allowed) → Mountain Meadow (2) → Forest Trail (1) → Championship Arena (0)
- **4 courses per world:** Bounce juggles, Feet only, Thighs only, Everything — 3 levels each
- **Counting:** the phone camera counts touches (body + ball tracking, runs on the phone), or tap buttons
- Install on Android: open the site in Chrome → menu → **Install app** / **Add to Home screen**

Files: `index.html` (screens), `app.js` (game), `scene.js` (horse + worlds), `audio.js` (sounds),
`camera.js` + `detector.js` (camera counting), `sw.js` (offline), `test/sim.mjs` (detector tests: `node test/sim.mjs`).
